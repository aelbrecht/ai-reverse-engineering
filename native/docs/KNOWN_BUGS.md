# Known bugs

No defects have been recorded for this new project. This does not establish that
an implementation exists or passes checks. Planned implementation gaps belong
in [the roadmap](ROADMAP.md).

For each observed defect, record the affected revision/date and scope, status
(open, deferred or awaiting confirmation), reproduction route, expected versus
observed behavior, evidence reference and any established cause. Keep hypotheses
distinct from findings. Link the repair and its bounded verification when done.

Respect explicit deferrals. A delivered repair awaiting visual or listening QA
remains qualified until that check occurs. Keep detailed captures and logs under
`../../work/`; do not copy them into this file or the repository.
